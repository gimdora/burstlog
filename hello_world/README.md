# Overview

I am building a personal software portfolio this semester to grow as a software engineer by completing three self-directed learning modules across different technology areas. This first program is the traditional "Hello World", a small Python script that greets the user and lists the three modules I plan to complete.

The software is a command-line program written in Python. When run, it prints a welcome banner, calls a 'greet' function to print a personalized greeting, and then prints a numbered list of the three modules I will work on during the upcoming sprints (Web Apps, Mobile App, and Cloud Databases).

My purpose for creating this software is to verify that my development environment (Python, Git, Visual Studio Code, and a public GitHub repository) is fully set up before I start the larger module projects, and to practice the full submission workflow that every module in this course requires: write the code, fill in the README, record the demo video, and upload the result.


# Development Environment

I developed this software in Visual Studio Code, using Git for version control and a public GitHub repository for publishing the code. The program runs from the integrated terminal with 'python hello_world.py'.

The program is written in Python 3 and uses only the built-in standard library (no external packages). It demonstrates a module docstring, a type-hinted function, an f-string for formatted output, a list, and a 'for' loop with 'enumerate' to produce numbered output.
