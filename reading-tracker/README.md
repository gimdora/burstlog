# Overview

I made this project to learn how a server side web framework actually works. Before this module I only made static HTML pages, so I had no experience with routing, templates, or saving data to a database from a web app.

This is a small Reading Tracker built with Django. It has two pages. The first page at `/books/` shows all the books I added and has a form to add a new one. The second page at `/books/<id>/` shows one book with its notes, and a form to add a new note. The data is saved in a SQLite database through Django's ORM.

To run the test server on your computer:

```
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Then open `http://127.0.0.1:8000/` in your browser. The root URL redirects to `/books/`.

I picked this project because I wanted something I would keep using after the module is over. Now I can track my reading list in one place instead of using a paper notebook.

# Web Pages

The app has two HTML pages and both are generated by Django views.

**`/books/` (list page).** This is the home of the app. It shows every book in the database, newest first. Each book is a link that goes to the detail page for that book. There is also a form at the top of the page to add a new book (title, author, status dropdown). When the form is submitted, the `book_list` view in `views.py` saves the new book in the database and redirects back to the same page, so the new entry shows up in the list. The number of notes shown next to each book is calculated when the page loads.

**`/books/<id>/` (detail page).** This page shows the title, author, and status of one book, and all the notes for it. The page also has a form for adding a new note. When the form is submitted, the `book_detail` view saves the note and redirects back, so the new note shows up.

The user clicks a book on the list page to go to its detail page, and uses the "Back to all books" link on the detail page to return. Both pages share a `base.html` template that has the header, styling, and page layout, so I only had to write that part once.

# Development Environment

I used Visual Studio Code on Windows to write the code, and ran the Django commands from the integrated terminal. For version control I used Git and pushed the code to a public GitHub repository.

The language is Python 3. The only library I added is Django itself. For the database I used SQLite, which is the default backend in Django, so I did not have to install anything else. For the page styling I put the CSS inside the base template instead of a separate static file, because the project is small.
